# Publication notes

This repository starts from a reviewed source snapshot with a fresh initial commit. It does not import the older private development repository's Git history, device logs, local notes, or signing/build artifacts.

The initial commit uses the maintainer's public GitHub identity and a GitHub noreply address. No co-author attribution is included.

## Included

Native iOS sources, build configuration, bundled assets and notices, a GPL-3.0-or-later license, portable setup, architecture, scope/privacy/validation guides, and issue/PR templates.

## Publication checks

The snapshot was checked for the previously identified machine/device details, the local private Git email, credential/private-key patterns, and unexpected sensitive artifact names. Documentation links and bundled notices were checked. Such checks reduce disclosure risk; they are not a guarantee that every security issue has been identified.

## For future changes

- Keep account sessions, signing keys/profiles, SDKs, downloaded music, and logs out of commits.
- Review author metadata and staged changes before pushing.
- Preserve the GPL and third-party notices.
- Redact personal data in screenshots and issue reports.
- Use only music and services you are authorized to access.
